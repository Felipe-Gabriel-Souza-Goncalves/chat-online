## ✏️ Objetivo
O intuito do projeto é um site que você possa conversar com qualquer pessoa criando salas e códigos <br>
o projeto não tem a intenção de ter uma estrutura completa de um app chat, apenas para conversas simples <br>
e temporárias, **não** compartilhe informações sensíveis ou relacionados.
